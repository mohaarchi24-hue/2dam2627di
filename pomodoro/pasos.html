Prompt 1 · Diseño Visual y Funciones Avanzadas

Solicitud para rehacer la app con una paleta de colores Dark Mode/Pastel, fondo acogedor de estudio, temporizador circular y contadores completados.

"Crea una aplicación web completa y profesional de un temporizador Pomodoro en un único archivo (HTML con CSS y JavaScript integrados). Debe ser totalmente responsiva, moderna y con un diseño impecable.

Diseño y Estética:
1. Fondo e Interfaz: Utiliza un fondo elegante y relajante con una imagen de alta calidad de Unsplash basada en un espacio de trabajo minimalista o estudio acogedor (mediante URL directa de images.unsplash.com), aplicando una capa semitransparente (overlay) o un efecto de desfoque suave (glassmorphic/backdrop-filter) para garantizar excelente legibilidad.
2. Paleta de Colores Moderna: Olvida los colores planos primarios. Usa una paleta pastel o tono neón suave (estilo Dark Mode premium), donde los tonos cambien suavemente mediante transiciones CSS al cambiar de modo (ej. verde menta/esmeralda para concentración, azul sereno para descanso corto, y morado/lavanda para descanso largo).

Requisitos de Funcionalidad:
1. Modos de Tiempo Personalizables:
   - Modo Concentración / Trabajo (por defecto 25 minutos, ajustable a 60 min u otros).
   - Descanso corto (5 minutos).
   - Descanso largo (15 minutos).
2. Controles y Visualización:
   - Botones de Iniciar, Pausar y Reiniciar (Reset) con animaciones al pasar el cursor (hover).
   - Un gran temporizador digital acompañado de un anillo de progreso circular fluido que se vaya consumiendo a medida que pasa el tiempo.
   - Cambio del título del navegador (document.title) para ver el tiempo restante en la pestaña.
3. Panel de Estadísticas Completo:
   - Contador de sesiones de trabajo / Pomodoros completados.
   - Contador de descansos cortos realizados.
   - Contador de descansos largos realizados.
   - Indicador de ciclo actual (ej. "Pomodoro 3 de 4") y cambio automático al descanso largo tras 4 Pomodoros.
4. Alertas y Personalización:
   - Reproducción de un sonido suave de aviso (usando Web Audio API para no depender de archivos externos) al terminar cada temporizador.
   - Modal o desplegable de ajustes para modificar la duración de cada modo y activar/desactivar el sonido.

Proporciona únicamente el código completo en un solo bloque de código, listo para copiar y guardar como index.html."
Prompt 2 · Ajuste de Contadores de Descansos

Revisión específica para garantizar que se incluyera el seguimiento numérico exacto de los descansos realizados.

"Añade un contador explícito en la sección de estadísticas que registre cuántos descansos cortos y cuántos descansos largos ha realizado el usuario durante la sesión actual."
